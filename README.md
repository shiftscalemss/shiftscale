# ShiftScale Engineering LLP — Website starter

A responsive corporate website concept for ShiftScale Engineering LLP.

## Run locally

This is a static website. You can open `index.html` directly in a browser, or use VS Code Live Server.

## Before publishing

1. Replace `[Add official business email]`, `[Add business phone number]`, and `[Add business office address]` in `index.html`.
2. In `script.js`, replace `YOUR-EMAIL@example.com` with the official enquiry email.
3. Replace the sample Unsplash photography with approved company/product images where available.
4. Update the product categories, partner details and company copy to match actual operations.
5. Connect a backend and database if you need enquiry storage, product management or a secure admin dashboard. The current form opens the visitor's email application; it does not store enquiries or provide admin authentication.

## Included

- Responsive single-page corporate website
- Sticky navigation and mobile menu
- About, products, industries, process, value proposition and contact sections
- Enquiry form with required-field validation and email draft
- SEO title, description and Open Graph metadata

## Notes

The photography is loaded from Unsplash and requires an internet connection. All company-specific contact information and unverified claims are intentionally left as placeholders.
